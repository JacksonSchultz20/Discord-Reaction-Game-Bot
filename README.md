# Discord Reaction Game Bot 

A Discord bot that was created for the r/teenagers discord server. It is a reaction game that sends messages out to specified text channels for people to react with and score points for their team. 
It also includes functionality for a logs channel 

---

## Features

- Players join a team which alternates every time someone joins to keep the teams balanced in players
- Start and stop game rounds with discord commands
- Automatic leaderboard updating
- Trap reactions that will deduct points from player and team score
- Logs all actions in a separate logs channel
- Persistent data to prevent loss from turning bot off
- Reset commands to clear leaderboard and team data
- Only users with specified role can run game commands

- ---

## Commands

- `!startround` - Start a new game round
- `!stopround` - Stop the current round
- `!resetgame` - Reset all score and team data

- > Only users with the specified role can run these commands.
